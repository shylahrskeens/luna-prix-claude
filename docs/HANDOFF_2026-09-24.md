## How to ship a change

1. `npm run dev` (check `lsof -iTCP:5173` first; an old server may still be running).
2. `npm run check` before committing anything that touches `src/sim` or `src/data`.
3. Commit, `git push`.
4. Deploy is **manual**: `gh workflow run pages.yml --ref main`, then `gh run watch <id>`.
5. Verify: `curl -sL <live url> | grep -o 'assets/index[^"]*\.js'` shows a new hash.

Shy asked that every finished batch be pushed AND deployed so the judges see it.

## What the game has now

## Traps (cost real time)

- In the automation tab, if you set `lunaPrix.race.paused = true` for a screenshot,
  **unpause it after** — Shy watches the same tab. Screenshots often time out there.
- Anything on a flight over a steep slope must be placed in **world space**
  (`worldToRoute` in `src/data/bonus.ts`), then re-probe with `tools/rampprobe.ts`.
- New jumps must land on a **long straight**; landing near a spiral or icy corner DNFs bots.
- Headless A/B toggles: `LUNA_TRACE=1 LUNA_TRACE_RACER=<name>`, `LUNA_NO_ITEMS=1`,
  `LUNA_NO_SPECIAL=1`, `LUNA_UNIFORM_KARTS=1`.
- The Mixer pack lives in `public/assets/axie/` (77 MB subset); don't commit the full 510 MB pack.
