## Title
Luna Prix

## One line
An Axie kart racer where the Axie's class decides how the kart drives and which battle move it brings.

## Playable builds
One build, installed through the browser. Same link everywhere.

- **Browser** — https://shylahrskeens.github.io/luna-prix-claude/ — open the link, nothing to install.
- **Windows** — same link — open in Chrome or Edge, then Install Luna Prix from the address bar. It opens in its own window.
- **macOS** — same link — open in Chrome or Edge, then Install Luna Prix from the address bar. In Safari, File → Add to Dock.
- **Android** — same link — open in Chrome, then Add to Home screen from the ⋮ menu. Touch controls appear automatically.
- **iOS / iPadOS** — same link — open in Safari, then Share → Add to Home Screen. Touch controls appear automatically.

## Repository
https://github.com/shylahrskeens/luna-prix-claude — public. The account `jaatster` has been invited.

## Controls and supported devices
Keyboard: W or ↑ accelerate · S or ↓ brake and reverse · A/D or ←/→ steer · Space or Shift hop, hold to drift · Space in the air trick · E class special · Q look back · R reset to the track · Esc pause. All rebindable in Settings.
Gamepad: left stick or d-pad steer, RT or A accelerate, LT or B brake, RB/LB/X drift, LB class special, Y look back.
Touch: a thumb stick, pedals, a drift button and a special button appear on a touch screen.
Runs in any browser with WebGL2. No install, no wallet, no backend. Quality steps itself down once if the frame time will not hold.

## Known issues
- Multiplayer is offline. The client and an authoritative server sim exist and have been run end to end as two headless Node clients on localhost, but no server is hosted, so the menu says "Offline — point it at a race server". Nothing in single player depends on it.
- Rank, coins and leaderboards are local to the browser profile. Clearing site data resets them. There is no account.
- Frame rate is verified on the development machine only. No measurement exists on a low-end GPU or a phone.
- The UI typeface is fetched from Google Fonts. With no network the game still runs and falls back to a system font.

## Disclosures
**Material AI use.** The code was written with Claude (Claude Code) across several sessions, from a prompt bible supplied by the owner, who directed the design and made every product decision. Claude wrote the implementation and the validators and harnesses that found the defects. Some earlier exploratory work was done in Grok Build; none of that code is in this repository.
**Pre-existing work and starters.** None. The repository was started from an empty directory for the Vibeathon. No template, boilerplate or starter kit.
**Dependencies.** One runtime dependency: three.js (MIT). Build and test only: TypeScript, Vite, esbuild, ws. No framework, no game engine, no physics library.
**Assets.** No third-party assets ship in the build. Every model, track, effect and sound is generated by code in this repository. The UI typeface is Inter from Google Fonts (SIL Open Font Licence). The official Axie 3D asset pack was downloaded and evaluated during development; it is not used, not shipped, and excluded from the repository.
**Contributors.** One person, the repository owner. No team.
