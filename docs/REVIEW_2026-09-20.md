# Luna Prix — pre-submission defect review, 2026-09-20

Read-and-reason review. No source was changed. `npm run check` was run unmodified and
passes end to end (typecheck, geometry, 21 headless races, finish check — `dnf 0`, times
ascending, all publishable). Everything below was traced in the code; where I could not
reproduce a path I say so.

---

## BLOCKERS

### B1 — The pause menu's "Settings" button silently destroys the race
`src/ui/screens.ts:1176` → `src/main.ts:212-213` → `src/main.ts:515-522`

`pauseOverlay`'s Settings button calls `app.go('settings')` directly, bypassing
`onResume`/`onQuit`. `go()` opens with `if (this.race) this.endRace();`, and `endRace()`
calls `this.race.dispose()` and nulls it. No confirm, no way back — Settings' own back
button goes to `home`.

**Trigger:** start any race → Escape → Settings. The race is gone.
**Fix:** give `pauseOverlay` a fourth callback the App implements without tearing the race
down, or drop the Settings button from the pause overlay for the submission.

### B2 — Time Trial pays a guaranteed 1st: coins, a win, a podium and a track unlock
`src/main.ts:377-379` (`fieldSize: mode === 'timeTrial' ? 1 : 8`, `soloGhost: true`)
→ `src/main.ts:455-460`, `476-480`

A time trial builds a one-car field, so `buildResult()` always returns `finish === 1`.
Every finished time trial pays the P1 purse (150 coins), increments `p.wins` **and**
`p.podiums`, and satisfies Ruin's `unlock.kind === 'podium'` gate
(`src/data/tracks/ruin.ts:68`).

**What a judge sees:** three time trials → Records reads `Wins 3`, `Win rate 100%`
(`src/ui/screens.ts:991-993`), 450 coins, Ruin unlocked without ever racing a rival.
**Fix:** gate the reward block on `result.entries.length > 1`; pay a flat time-trial purse
and skip `wins`, `podiums` and the podium unlock.

### B3 — A demotion is announced as a promotion
`src/main.ts:466-469`

```ts
const after = divisionFor(p.rating).name;
if (after !== before && p.rating > 0) promoted = after;
```

No direction check. Drop a division in ranked and the results screen prints
`Promoted to Scrap.` (`src/ui/screens.ts:683`).
**Fix:** compare ratings, not just names — `if (p.rating > ratingBefore && after !== before)`.

### B4 — Tail-expiry finishers get an invented time, shown and saved as real
`src/sim/race.ts:269-283`, `396-402`, `404-410`; `src/main.ts:456, 472`;
`src/ui/screens.ts:626, 639`

When the finish window expires, `projectedFinish()` fabricates a time and
`finishRacer(r, false, projected)` stores it. Two consequences:

1. `finishRacer` is **never** called with `timedOut = true` (only `race.ts:280` and `:386`,
   both `false`), so `progress.dnf` is dead code — every `e.dnf ? '—' : …` branch in the
   results table is unreachable and `me.dnf ? 10 : purse[…]` never pays.
2. The fabricated number is displayed as the player's race time and passed to
   `submitRecord` as `me.totalTime`, so it can become their **best race**. With `p.raw`
   under 0.05, `done` clamps to 0.05 and `perLap = this.time / 0.05`, giving four-figure
   minute times.

**Fix:** pass `timedOut: true` in the `rest` loop at `race.ts:277-281`, so those entries
read DNF and `main.ts:472`'s existing `me.dnf ? 0 : …` guard takes effect.

### B5 — Repeated frame errors become an unbounded rebuild/toast loop
`src/main.ts:619-632`

```ts
if (this.frameErrors >= 3) { this.frameErrors = 0; try { this.go('home'); } catch {} }
```

Resetting the counter defeats the "bail out once" intent. If the error source is the
renderer (lost WebGL context — S7), the menu throws too, so the game toasts and rebuilds
the whole home-screen DOM roughly 20×/second, forever, with no message after the first.
There is no exit.
**Fix:** a `private bailedOut = false` flag — run the fallback once, then stop ticking and
leave a persistent message on screen.

## SHOULD-FIX

**S1 — `Infinity` is persisted into records; JSON turns it into `null`.**
`src/persist/store.ts:245-258` (same shape at `264-281`). `submitRecord` seeds a new row
with `bestLap: Infinity, bestTotal: Infinity`. If the first submission does not beat them
(`bestLap > 0` is false when the player completed no laps — reachable via B4) the row is
saved with `Infinity`, which `JSON.stringify` writes as `null`. Confirmed in node:
`41.2 < null` → `false`, so **that track's best lap can never be set again**;
`isFinite(null)` → `true`, so the `rec && isFinite(rec.bestLap)` guards at
`screens.ts:566-567` and `942-943` pass and `formatTime(null)` renders `0:00.000`. The
bonus equivalent (`store.ts:269`) would throw on `null.toFixed(1)` at `screens.ts:724,
770, 952` — I found no non-NaN score path that reaches it, so I am not claiming that one.
*Fix:* create the row only on a real improvement, or seed `0` and test
`rec.bestLap === 0 || bestLap < rec.bestLap`.

**S2 — The bonus-results navigation timer is unguarded.** `src/main.ts:509-511`.
`finishRace` checks `if (this.race === view)` before navigating (`:488-490`);
`finishBonus` does not. Finish a bonus event, then within 1.4 s Escape → Quit to menu: the
timer fires anyway and throws the player from Home onto a bonus-results screen.
*Fix:* capture `const view = this.race` and guard the callback identically.

**S3 — Mega Ramp has no time limit once `launched` is set.** `src/game/bonusRun.ts:106-131`.
The only timeout is `if (core.time > this.def.timeLimit && !this.launched)`. After
`launched` the attempt can only end via `else if (this.phase === 'flight')`, which needs an
airborne `update()` *after* the frame that set `launched`, then a grounded one. If
`launched` is ever set on a frame followed directly by a grounded frame, `phase` stays
`'run'`, no branch matches, the timeout no longer applies, and the only exit is Escape →
Quit. **I did not reproduce this** — the drift hop is ~0.3 s — but the state machine has no
backstop, and Luna Launch (`:196`) places its timeout the same way.
*Fix:* move the `core.time > timeLimit` check out of the `!launched` branch.

**S4 — Key rebinding has no cancel and no duplicate check.** `src/ui/screens.ts:1046-1071`.
Clicking a row installs a capturing `keydown` listener removed only by the *next* keypress
— navigate away and it stays armed, silently binding whatever is pressed next. Nothing
stops two actions sharing a code: bind `pause` to `KeyW` and W both accelerates and pauses.
*Fix:* also remove on blur/click-elsewhere, and reject a code already in use.

**S5 — A bonus run permanently restyles the shared race HUD.** `src/ui/hud.ts:296-303`.
`toastLive` writes `posEl.style.fontSize = '34px'` and `lapEl.style.fontSize/color`
inline and nothing restores them. `Hud` is built once (`main.ts:64`) and reused, so after
any bonus event the position and lap readouts stay at bonus sizing for the session.
*Fix:* clear those three inline styles in `Hud.prepare()`.

**S6 — "Erase profile" does not erase, and can resurrect an old save.**
`src/ui/screens.ts:1145-1154` vs `src/persist/store.ts:200-228`. The button hardcodes
`localStorage.removeItem('lunaprix.profile.v3')` instead of calling `resetProfile()`, and
clears neither `LEGACY_KEYS` (`store.ts:16`) nor `lunaprix.server`. `loadProfile` falls
back to the legacy keys, so on a machine with a v1/v2 save the erase is undone on the next
load — under a dialog reading "This cannot be undone." The call is also outside any `try`,
so it throws where storage is blocked and `location.reload()` never runs.

**S7 — No WebGL context-loss handling.** `src/main.ts:664-678`, `src/render/scene.ts:209`.
`boot()` tests for WebGL once; there is no `webglcontextlost`/`restored` listener anywhere
in `src/` (grep: no hits). A laptop waking from sleep drops the context, every
`ctx.render()` throws, and the session lands in B5's loop.

**S8 — Luna Launch is effectively hidden.** `src/ui/screens.ts:160` advertises "Mega Ramp
and Gator Gauntlet"; `src/data/bonus.ts:339-390` ships three events. See H2.

**S9 — A finished kart can fall out of the world during the tail.**
`src/sim/kart.ts:601-608` → `661-662`. `stepBounds` calls `triggerRespawn()` when a
finished kart is over a gap, but `triggerRespawn` returns immediately for
`mode === 'finished'`, so it falls forever — on camera, during the post-race cinematic.

## POLISH

- `src/persist/store.ts:192-193` — `Math.max(0, Math.floor(p.coins || 0))` returns `NaN`
  for a non-numeric `coins`, and `NaN` survives every later `+=`, making the shop
  permanently unaffordable. Needs `Number.isFinite` guards. Only reachable from an
  already-corrupt save.
- `src/main.ts:322-355` — `startNetRace` omits the `this.input.clearPresses()` that
  `startRace` and `startBonus` do (`:371`, `:405`).
- `src/main.ts:207-210` — `back()` and the unbounded `history` array are never used, and
  `'controls'` in `ScreenName` (`screens.ts:26`) has no case in `go()`'s switch.
- `src/persist/store.ts:218-223` — `saveProfile` swallows quota/blocked-storage failures
  with no signal; a judge in a private window loses everything silently.

## Honesty gaps (docs vs code)

**H1 — `npm test` fails. SHOULD-FIX.** `package.json` defines
`"test": "node --test test/*.test.mjs"` and there is no `test/` directory
(`ls test` → *No such file or directory*). No doc claims a test suite, so this is not a
false claim — but a judge who types `npm test` out of habit sees a failure. Remove the
script or point it at `npm run check`, which passes.

**H2 — "two bonus events" is wrong in four places. SHOULD-FIX.** `README.md:3`,
`docs/SUBMISSION.md:9`, `index.html:7` and `src/ui/screens.ts:154` all say two;
`src/data/bonus.ts:339-390` ships three (Mega Ramp, Luna Launch, Gator Gauntlet).

**H3 — "the only request it makes off the page is the Google Fonts stylesheet". POLISH.**
`README.md:7`. `index.html:11-13` preconnects to both `fonts.googleapis.com` and
`fonts.gstatic.com`, and the stylesheet then fetches woff2 files from gstatic. Two hosts.

**Claims I checked that hold up.** *No third-party assets* — `assets-incoming/` is
gitignored and greps for `assets-incoming|axie-3d|\.glb|\.gltf|GLTFLoader|TextureLoader`
across `src/` and `index.html` return nothing. *728 KB / 202 KB gzipped* — measured from
`dist/`: 727,626 B raw (493,455 + 219,605 + 12,879 + 1,687) and 200,682 B at gzip -9; the
doc's per-file breakdown matches byte for byte. *Three Axies are demo data* —
`source: 'mock-local'` is on all three (`src/data/axies.ts:133, 152, 171`) and on the type
(`:55`); "seven rivals" matches `RIVALS` (`src/sim/ai.ts:31-39`), "three circuits" matches
`src/data/tracks/index.ts`. *No chain code* — no wallet, contract or indexer reference in
`src/` or `server/`. *Multiplayer* — `SUBMISSION.md:114-116` claims it works and
`:164-167` states plainly that nothing is hosted; the adapter split and `server/index.mjs`
back that up. *Tooling* — `npm run check` ran here unmodified and passed.
